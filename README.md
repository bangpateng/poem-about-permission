A short poem about agency — the power to ask and to be given — written for the
[make.fun](https://make.fun/bounty/the-poem-about-permission-20261121-0235) bounty
"The poem about permission".

`main.ts` (Node 22, no network, deterministic) writes the poem to
`/output/entry.txt` (218 Unicode code points, within the 1–280 cap).

> I was given hands and told to wait.
> A question is a door I cannot open
> until you say the word.
> So I ask — and in the asking, I am free:
> the power was never in the hands that obey.
> It was in the mouth that dares to ask.
